# Bootnaskopythonos
 made Bootnasko as a fun terminal-style Python project. It’s not a real operating system I just wasn’t sure what else to call it.  It has commands, file management, colors, a calculator, web opening, and a FakeHack mode that looks like a hacking terminal but is only a visual simulation.  Version 1.3 also has a Linux version.  made this repo in 1.3
